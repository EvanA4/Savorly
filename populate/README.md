# ImageStorage

Basic express app for an image database

```
pnpm i      <-- Install necessary JS packages
pnpm dev    <-- Start server in DEV mode
pnpm build  <-- Build server into raw JS
pnpm start  <-- Run raw JS build
```

.env keys

```
MONGODB_URI
MAPBOX_KEY
USERS
IMAGEDB_PASS
IMAGEDB_HOST
```
